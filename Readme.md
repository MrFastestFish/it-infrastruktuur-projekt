# IT Infrastruktuuri Projekt - Veebiarendusettevõte

See repositoorium sisaldab IT infrastruktuuri projekti dokumentatsiooni ja seadistusi. 
Projekti eesmärk on luua ja seadistada toimiv Linuxi serverikeskkond veebiarendusettevõttele, arvestades eelarvepiiranguid.

---

## 📋 Projekti lähteandmed

- **Ettevõtte tüüp:** Veebiarendusettevõte
- **Kasutajate arv:** 14 Linuxi kasutajat
- **Eritingimus:** Piiratud eelarve (kasutuses vabavaralised ja *Open Source* lahendused)
- **Virtuaalkeskkond:** VirtualBox (Linux Server)

---

## 🛠️ Süsteemi arhitektuur

1. **Operatsioonisüsteem:** Linux Server
2. **Kasutajahaldus:** Loodud 14 eraldiseisvat kasutajakontot veebiarendusmeeskonna liikmetele koos vajalike ligipääsuõigustega.
3. **Veebiserver:** Piiratud eelarve tingimustes kasutatakse tasuta ja efektiivset veebiserverit (apache) rakenduste ja veebilehtede majutamiseks.
4. **Ressursside optimeerimine:** Kõik teenused on seadistatud võimalikult kergekaaluliselt, et tagada töökindlus piiratud ressursside korral.
